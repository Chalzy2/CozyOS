# Builder Handoff — M375 (Layer 4 — BuilderLearning, aggregator)

**Status:** Completed (scope: read-only aggregator only; Pattern/
Recommendation/Confidence engines explicitly not built — insufficient
signal, unchanged from M374).

## What this milestone did

1. Resolved a Gate 1 naming/scope conflict: the original brief called
   this work "M374," but M374 already existed in the repository with a
   different, completed scope (repair-history persistence). Adopted
   Rule 58 (Milestone Integrity) and Rule 59 (Implementation Contract
   Fidelity) to prevent this recurring, and opened M375 instead of
   reopening M374.
2. Filed `docs/builder/compose/M375-compose-report.md` (Phase 1, no
   code) — real ownership/composition/conflict/gap review, approved
   before any implementation began.
3. Created `core/modules/builder/learning-engine.js`, registering
   `window.CozyOS.BuilderLearning` — composes `BuilderObservation`
   (Layer 1), `UnderstandingEngine` (Layer 2), `AnalysisEngine`
   (Layer 3), `CozyMemory` (read-only), and the existing
   `window.CozyOS.LearningEngine` (read-only, via its public API only).
4. Modified `dashboard.html` — added one `<script>` tag loading the
   new engine after Layer 1-3, before `builder-orchestrator.js`.
   Verified as the only diff against the original file.
5. Found and fixed a real defect during verification: a redundant
   version-guard pattern (copied from `observation-engine.js`) that
   made version-conflict detection unreachable dead code. Fixed in the
   new file only; the same defect in Layer 1-3 files is left for a
   future correction milestone (see Improvement Report).

## What this milestone deliberately did NOT do

- Did not build a Pattern Engine, Recommendation Engine, or Confidence
  Engine — same insufficient-signal conclusion as M374 (2 repair
  records), independently re-confirmed, not just copied forward.
- Did not build a markdown/JSON registry loader — registries, metrics,
  and handoffs are reported as `available: false` with file pointers,
  honestly, rather than fabricated or invented.
- Did not touch `observation-engine.js`, `understanding-engine.js`,
  `analysis-engine.js`, or `leaning/learning-engine.js`.
- Did not fix the pre-existing version-guard defect in Layer 1-3, or
  the fact that `leaning/learning-engine.js` isn't loaded by any HTML
  entry point, or the `leaning`/`learning` directory typo. All three
  recorded in the Improvement Report as real, deferred findings.
