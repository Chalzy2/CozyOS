## 4. Why It Changed

- Layer 3 required an Analysis Engine — Layer 2 already generated graphs (Module/Dependency/API/Event/Ownership) but nothing reasoned over them into structured findings.
- Analysis Engine composes those graphs directly; no duplicated parsing was added — Tier A performs zero raw-text scanning of its own.
- Tier B's regex heuristics were added only where Decision 3 explicitly authorized new extraction (security/static-leak patterns), and nowhere else.
- AA-003 was opened, not fabricated findings, for the six capabilities with no existing signal — named "Insufficient Signal" per explicit correction, distinct from "Missing Feature."
- Rule 54 itself was revised mid-session: the first draft used a workable but differently-structured format; this message's specification is the authoritative, final version and supersedes it in place, same rule number.
- Rule 6 (compose, never duplicate) and Rule 50 (Compose Before Implementation) both satisfied — no competing engine was created anywhere in this milestone.
