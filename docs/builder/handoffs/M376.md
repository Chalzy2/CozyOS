## 4. Why It Changed

M375 built a read-only status aggregator (BuilderLearning) but
explicitly declined to parse the knowledge registries or answer
whether accumulated evidence justified building pattern-detection
logic. The M376 brief asked for exactly that missing piece — a Layer 5
that measures evidence honestly, without becoming speculative AI
reasoning. See the compose report for the full ownership/composition
review that confirmed this was a genuine gap, not a duplicate of
anything existing.

## 7. Known Limitations

- Cannot enumerate the handoffs directory (no browser `fetch()` API
  for that) — `getMilestoneHistory()` discloses this rather than
  guessing a total.
- Cannot track evidence growth over time — no prior snapshot exists,
  and this engine persists none of its own by design.
- "Repeated findings" / "repeated architectures," two categories the
  brief asks about, aren't tracked as first-class registry categories
  today — reported `notTracked`, not approximated from an adjacent one.
- Browser runtime not verified this session (Node `vm` smoke tests
  only — see verification report §9).

## 8. Next Recommended Milestone

**Not** M377-as-previewed (Pattern Engine) — this session's own live
evidence run shows Insufficient Evidence. The real next step is either
(a) continue normal engineering work and re-check
`getPatternReadiness()` periodically, with no calendar trigger, or (b)
a narrowly-scoped milestone to decide on evidence-snapshot persistence
if growth-tracking is wanted before (a) naturally resolves. See the
Improvement Report for the full reasoning.

## 9. Risks

LOW — read-only measurement engine, one new file, one new script tag,
no existing behavior touched. Open risk: `fetch()` behavior under
`file://` origins is unverified in a real browser (see §5 Known
Limitations) — degrades to honest `available: false` rather than
throwing if that occurs, per the fetch-failure test in the
verification report, but this hasn't been confirmed against a real
browser's actual `file://` fetch semantics.
